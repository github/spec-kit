# Presets

This directory contains first-party preset assets, catalog data, and the
scaffold for creating presets. The canonical user and author documentation
is published in the [Presets guide](https://github.github.io/spec-kit/presets/overview.html).

## Directory contents

| Path | Purpose |
| --- | --- |
| `catalog.json` | First-party preset catalog |
| `catalog.community.json` | Community discovery catalog |
| `lean/` | Bundled lean process preset |
| `constitution-sync/` | Bundled, opt-in constitution synchronization preset |
| `scaffold/` | Example package to copy when authoring a preset |
| `self-test/` | Repository test fixture for preset contributions |

Community presets are independently maintained. Catalog inclusion is not a
code review, security endorsement, or support commitment; users must vet
third-party presets before installation.
