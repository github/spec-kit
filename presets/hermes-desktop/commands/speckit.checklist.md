# /speckit.checklist

Run the convergence checklist for a feature.

## Usage

```bash
/speckit.checklist <feature_name> [--interactive]
```

## Options

- `--interactive` — Step through checklist in ConstitutionWizard pane

## Checklist Items

- [ ] All FRs implemented and verified
- [ ] All scenarios tested
- [ ] All edge cases handled
- [ ] Constitution gates re-validated
- [ ] Convergence diff reviewed
- [ ] Documentation complete

## Output

Pass/Fail with detailed findings per item.
