# Community Presets

Find presets that adapt Spec Kit's templates, commands, and terminology to your process. Search by purpose, author, or tag, then open a preset to explore its requirements and release details.

> [!NOTE]
> Community presets are independently created and maintained by their respective authors. Maintainers only verify that catalog entries are complete and correctly formatted — they do **not review, audit, endorse, or support the preset code itself**. Review preset source code before installation and use at your own discretion.

This directory is generated from the [community preset catalog](https://github.com/github/spec-kit/blob/main/presets/catalog.community.json). Versions shown are catalog-listed releases, not live repository releases. The community catalog is discovery-only.

Star counts are GitHub repository totals captured at the last documentation build. Presets in the same repository share a count; stars are not a safety endorsement.
